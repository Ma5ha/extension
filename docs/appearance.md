# Izgled — TAB-10-V

Settings sada nudi Mix your colors (accent i dvije boje pozadine, 0–100% miješanje), Card material (0–100% providnost i odvojeni blur) i Background image (lokalni JPG/PNG/WebP). Ručni light/dark slider ostaje. Uključivanje custom colors važi u obje teme; Reset colors vraća fabričke boje bez brisanja slike ili rasporeda.

Providnost 100% uklanja fill kartica i zajedničkih površina; obrubi, tekst i kontrole ostaju. Blur je nezavisan, za potpuno jasan pogled kroz kartice postaviti ga na 0. Modal Settings ostaje neproziran. Miješanje koristi semantičke tokene i CSS color-mix; akcenat dobija crnu ili bijelu button oznaku prema većem luminance kontrastu. Proizvoljne korisničke boje/slike nisu provjerene za WCAG i ne predstavljaju tvrdnju o usklađenosti.

Lokalni upload prihvata raster do 3 MB i 40 MP, provjerava MIME/dekodiranje i čuva base64 data URL u zasebnom polju postojećeg storage adaptera. Bez udaljene slike/CDN-a, slanja fajla na server, novih dozvola ili kopiranja slike u repo/logove. Slika je globalno podešavanje browsera, zajedničko prostorima i tabovima; cover/contain, theme overlay 0–100% i Remove image su dostupni. Overlay prati light/dark temu (bijeli/crni sloj). Uklanjanje vraća gradijent i oslobađa vrijednost storage polja. Ne traži unlimitedStorage; popunjen browser storage se prikazuje postojećom porukom o neuspjelom čuvanju.

Implementacija: src/adapters/settings.ts (validacija i postojeće per-field čuvanje), appearance.ts (čiste transformacije), useSettings.ts (CSS/tema sinhronizacija), AppearanceSettings.tsx/CSS (kontrole/upload), theme.css/App.module.css (slojevi i tokeni). Stare postavke ostaju kompatibilne, raniji glass vrijednosti ostaju nepromijenjene, nove se prihvataju do 100.

Provjere: typecheck, lint bez upozorenja, produkcioni build sa postojećim OAuth klijentom i git diff --check prolaze. HTTP UI: uključene custom boje, glass 100 i blur 0; direktno očitavanje renderovanog CSS-a potvrđuje opacity 0. Upload vlastitog ranijeg neprivatnog UI screenshot-a kroz file chooser potvrđen; data image i providnost ostaju poslije reloada. Probna slika je potom uklonjena kroz UI. Light/dark teme su prikazane. Screenshot kontrola: /private/tmp/tabora-appearance-settings.png. Stvarni Chrome storage/quota, više tabova, ostali raster formati/loši fajlovi/limiti, sve fit/overlay vrijednosti, kontrast proizvoljnih paleta, uski/zoom/reduced-motion i puna tastatura nisu potvrđeni. Nema novih testova/QA skripti.

## TAB-10-W — organizacija i stilovi

Settings ima Appearance/Widgets/Connections/Data sekcije sa nativnim dugmadima i vidljivim aktivnim stanjem. Appearance počinje pet preglednih kartica stilova, zasebnim Apply i Reset appearance. Reset mijenja theme/fontSize/backgroundMotion/material/colors/fit/overlay, a backgroundImage/layout/servisne i widget postavke ostaju. Uklanjanje slike je zasebna postojeća radnja. Preseti mijenjaju theme/colors/glass/blur; font i slika ostaju. Quiet light/Night orbit koriste postojeću bazu, Warm sand/Aurora/Clear space koriste custom boje. Pregledi su male CSS reprezentacije, bez novih slika ili zavisnosti.

Connections nudi postojeći Google Connect/Disconnect; Enabled je lokalna uključenost, ne tvrdnja da token radi. Data objašnjava čuvanje i privatnost; izvoz/uvoz nije dodat ovim korakom. Provjere: typecheck/lint/build/diff-check, HTTP Apply/Reset, sve sekcije, light/dark, 390px i osnovni Tab fokus prolaze. Chrome OAuth iz panela, sva svojstva uz korisničku sliku, puna keyboard/zoom/reduced-motion matrica ostaju. Screenshot: /private/tmp/tabora-settings-presets.png.
